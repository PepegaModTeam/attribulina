# Undercover PC gameplay Lua API. <kind> <name> <signature>  # description
# Made by scripts/lua_api/run_others.sh from the Xbox 360 debug build (nfs-data/SpeedDebugOpt-enUS.exe and its
# PDB) and the PC build (exes/pc/undercover/nfs_steam.exe): the functions, methods and objects that
# LuaBindery::BindToGameCode, BindCustomMethods and the LuaFuncBinderProxy objects bind, the ILuaBindable
# classes bind or look up (_ALERT as a bare global), the numbers the game sets in GRaceType, the M<Name>
# globals (messages the global lookup sends), the E<Name> globals (events marked callable from Lua) and
# ChangeState. The game opens no Lua standard library.
# The PC and Xbox 360 versions run Lua 5.1 and nearly the same handlers. No retail 360 executable is at hand,
# so the 360 debug build stands in for it: its symbols give the names and types. The PC build binds the same
# names, numbers and messages, and the same events plus ECancelAutoSaveRequest; scripts/lua_api/scan_uc360.py
# compares them (uc_builds.txt in its work folder). The stub notes are the PC's, and a line says so where the
# 360 debug build differs. The E<Name> lines come from the PC's event definitions.
# The retail handlers also use names that neither build binds, so they are not listed: Most Wanted's
# Demo.SetRaceCompleteForFE and Demo.StorePursuitRepForFE; Pro Street's GTier (IncrementConsecutiveRacesWon,
# IncrementConsecutiveRacesLost), GHub:IsCareer, GRacerInfo:SetTimer, Game.AwardPlayerBounty,
# Game.ShouldHideSpeedTrap, Game.WarpPlayerAndWingmanToMarker and MiniMap.AddEngagedRace; and
# EShowPostPursuit, GRaceType.TakeDown and Game.GetSimableHealth.
# Signatures and descriptions of names Pro Street also binds come from data/lua/prostreet_pc.txt and were not
# checked against this game; the stub notes ("Does nothing on PC.") were. The E<Name> and M<Name> lines are
# written from this game's own definitions.
# Types: number, string, boolean, table, instance (GRuntimeInstance userdata), simable (ISimable userdata),
# racerinfo (GRacerInfo userdata), handle (GWrapper userdata), ignored (a message argument the game never
# reads).
