## Executable paths

Executables are expected to be found under the `exes` directory in the repository's root.

The tree is expected to look something like this:

```
exes
├───gamecube
│   └───mw-vanilla
├───pc
│   ├───carbon
│   ├───mw
│   ├───undercover
│   ├───world-2009-beta
│   ├───world-2010-beta
│   └───world-final
├───ps2
│   ├───mw-beta
│   └───mw-early-opm-demobeta
└───wii
    └───nfsc-vanilla
```

Inside each directory, there should be the:

- game executable
- IDA database (.idb)
- IDA .map file
